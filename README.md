# Alice in Cradle 联动（DGStudio 模块）

《爱丽丝的摇篮》（Alice in Cradle）× DGStudio 联动模块。游戏端模组（`AliceInCradleLink`，BepInEx 5 插件）读取 HP / MP / EP 等游戏数值并上报给 DGStudio；模组只做数据采集，模块也只登记变量——强度换算与设备动作全部在「事件流」画布里完成。模块依赖：无（仅 Python 标准库），游戏端模组及其全部依赖随模块自带。

## 功能

* 模组**按数据变动即时上报**命名通道（`HP`、`MP`、`EP`、`Hurt`、`Heal`、`MpLost`、`MpGain`、`Orgasm`、`Orgasming` 等，无变动不通信），每个通道都是「事件流」变量表里的一个变量，用 `{HP}`、`{HPmax}` 直接引用；
* `Hurt`/`Heal`/`MpLost`/`MpGain` 来自**游戏调用事件**，按**脉冲合并窗口**上报（时长可在模组配置「每单次伤害脉冲时间」调整）：首个事件立即开口输出并开启窗口；窗口内的新事件并入同一脉冲（不拆分输出）；窗口结束时一次性输出合并累计总量并归零——窗口内输出严格递增、窗口之间以 0 隔开；
* 血量清零后的 overkill 过量伤害、魔力槽空时的施放消耗，均按游戏显示数值上报；
* 设备读数（`StrengthA`、`StrengthB`、`Battery`、`Connected`、`Pressure`）同样登记成变量，并按同名字段回传给游戏显示；游戏内按 **F9** 开关 DGStudio 状态面板，面板显示回传字段与本地 HP / MP / EP、高潮计数等数值及上报状态；
* 默认服务地址 `127.0.0.1:8920`。

## 在事件流里接线（设备动作的唯一入口）

模块不再内置「输入映射表 / 输出映射表」——设备只能由「事件流」的**写入卡片**驱动。把本模块的变量接进设备，在「事件流」页这样搭：

1. 输入页拖本模块的读数卡（如 `Alice · 当前生命`、`Alice · 本期掉血`），或用「读取变量」卡片按名引用 `{HP}` `{Hurt}`；
2. 中间用公式 / 范围映射等卡片做换算，例如血量越低强度越高：`({HPmax} - {HP}) / {HPmax} * 200`；
3. 输出页接「写入设备」卡片（通道强度 / 波形 / 开火 / 电击等），把上一步的结果写进去；触发时机用「值变动时」「条件成立时」「周期」等驱动卡选择；
4. 想把设备状态回传游戏：`StrengthA` / `StrengthB` / `Battery` / `Connected` / `Pressure` 由本模块自动回传，无需连线。

急停、暂停等设备动作也一律走事件流；模块自己不再下发任何设备命令。

## 安装

### 模块安装（DGStudio）

在 DGStudio「模块」页的在线列表中获取本模块，安装时优先合并仓库自带的依赖，卸载 / 更新即热重载生效。也可手动把本仓库 `modules/<模块 id>/` 文件夹整个放入应用目录的 `modules/` 下。

### 游戏模组安装

模块页提供**一键安装**：

1. 打开「模块」页，在「Alice in Cradle 联动」卡片的**游戏模组**行填入游戏根目录（含 BepInEx 的那一层），或点「自动扫描」搜索。
2. 点安装，模组会被释放到 `BepInEx/plugins/AliceInCradleLink/`。路径会被记住，之后可一键安装。
3. 启动游戏，到「事件流」页把模组上报的通道接进设备写入卡片（见上文「在事件流里接线」）。

目标目录**缺 BepInEx 时自动安装模块携带的 BepInEx 5 发行包**再释放模组——只要选中的是游戏根目录（含游戏主程序 exe）即可，全程无需联网。

## 配置与使用

DGStudio 侧（「模块」页）：

* 服务地址在模块卡片内配置（默认 `127.0.0.1:8920`）；
* 「设备读数采样间隔」决定 `StrengthA` / `Battery` 等变量多久刷新一次；
* 换算与设备动作不在模块里配置——变量登记好之后，全部在「事件流」画布上用读取卡片 + 写入卡片接线；
* 旧版的「输入映射表 / 输出映射表」设置项已随模块直写设备一并取消，装载时会自动清掉遗留数据并在日志里提示改到事件流接线。

游戏侧（BepInEx 配置，写入 `BepInEx/config/dev.dgstudio.aliceinradle.link.cfg`）：

| 配置项 | 说明 |
| --- | --- |
| 启用联动 | 关闭后模组不再读取游戏状态，也不再与 DGStudio 通信。 |
| DGStudio 地址 | DGStudio「Alice in Cradle 联动」模块的数据服务地址，默认端口 8920。 |
| 每单次伤害脉冲时间 (秒) | 伤害/回血/耗蓝/回蓝脉冲的存续时长：首个事件立即输出并开启窗口；距上次输出小于该时长的新事件并入同一脉冲（只累计、不拆分输出），窗口结束时一次性输出合并累计总量并归零。设小则逐事件拆分，设大则持续伤害合并为持续脉冲。 |
| 回传轮询间隔 (秒) | 拉取设备回传字段的间隔。 |
| 单次变化生效上限 | 差分信号超过此值视为数据异常（读档/换场），不产生信号。 |
| 高潮状态保持 (毫秒) | `Orgasming` 信号在一次高潮后保持为 1 的时长。 |
| 显示/隐藏热键 | 切换 DGStudio 状态面板（默认 F9）。 |
| 默认显示 | 启动时是否显示面板。 |
| 面板 X / 面板 Y | 面板左上角横 / 纵坐标。 |

## 常见问题

* **游戏更新后联动停了？** 模组启动时若发现玩家组件缺少 hp/maxhp/mp/maxmp/ep 字段，会记录「当前游戏版本可能与此模组不兼容，联动已停止」——需等待模组适配新版本。游戏版本不兼容导致事件钩子安装失败时，对应通道自动回退为逐帧差分，联动不中断。
* **状态面板不见了？** 游戏内按 F9 切换显示；若面板绘制异常，模组会自动关闭面板防止刷屏，并在日志记录错误。
* **接线改了要重启吗？** 不需要，「事件流」画布与模块设置都是即时生效；只有服务地址 / 端口需要重新开关一次模块。
